# DutyRoute antislop follow-up 001

All seven findings in audit 001 are fixed. This pass removes promotional copy and decoration while preserving the real map, scheduling model, printable records and export controls.

## Changes

1. Results tabs now have one tab stop, Arrow Left/Right with wraparound, Home/End navigation and focusable panels. Schedule-row focus is drawn inside its border.
2. Log captions and schedule column labels use sentence case without wide tracking.
3. “Trip planner” replaces the slogan; the empty state gives specific location-search instructions. The workspace begins 55 pixels higher in the same desktop viewport (212px before, 157px after).
4. Removed the decorative wordmark gesture and bare hash link. The actual connected duty grid remains the identity motif.
5. “Trip results” replaces two introductory labels. One instruction explains all schedule-row map actions.
6. Every map stop is a named keyboard button: Enter/Space toggles its popup and Escape dismisses it. Focus uses a heavier teal ring; the route line is noninteractive. Reduced-motion preferences disable smooth schedule-to-map scrolling.
7. Attribution now uses opaque white and teal links, guaranteeing 7.57:1 contrast regardless of map tiles.

No new assets, sections, dependencies or scheduling features were added. Removed the no-op string replacement in directions. `DESIGN.md` records the retained choices and their purposes.
